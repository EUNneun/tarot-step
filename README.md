# TarotStep

타로 78장의 핵심 키워드와 기본 해석을 반복 문제풀이로 익히는 모바일 웹 MVP입니다.

## 현재 기능

- 문제은행 250문항
- 초급/중급 자동 혼합 출제
- 오답 문제 우선 복습
- 취약 카드 우선 출제
- 카드별 숙련도 기록
- 누적 문제 수 / 정답률 / XP / 현재 레벨 표시
- 브라우저 `localStorage`에 학습 기록 저장

## 레벨 기준

카드별로 **3회 이상 풀이 + 정답률 75% 이상 + 최근 2회 연속 정답**이면 해당 카드를 숙련으로 판단합니다.

숙련 카드 수에 따라 `입문 → 기초 → 성장 → 숙련 → 고급 → 마스터`로 올라갑니다.

## 실행

정적 웹이므로 별도 서버나 DB가 필요하지 않습니다.

- `index.html`
- `styles.css`
- `data.js`
- `app.js`

Vercel 또는 GitHub Pages에 그대로 배포할 수 있습니다.

## 데이터 저장

현재 사용자 학습 기록은 서버가 아니라 **같은 브라우저의 localStorage**에 저장됩니다. 따라서 다른 기기와 자동 동기화되지는 않습니다.
